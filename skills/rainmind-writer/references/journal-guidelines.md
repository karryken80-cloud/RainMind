# 获取期刊官方要求

对目标期刊依次记录（写进 manuscript/outline.md 头部）：
- 官网 Author Guidelines / Instruction for Authors URL
- 文章类型（Article / Letter / Research Note）与字数限制
- 摘要结构（是否 structured、字数）
- 正文 section 要求与顺序
- 图表：数量上限、尺寸、分辨率、单独上传或内嵌、图注格式
- 参考文献格式（编号/作者-年，.bst/.csl）
- 模板：Word template / LaTeX class 下载地址
- 投稿系统要求（ORCID、作者贡献、数据可用性声明等）

检索方式：打开期刊官网 → For Authors → Guide for Authors / Manuscript Template；或 web 搜索“<期刊名> author guidelines template”。
