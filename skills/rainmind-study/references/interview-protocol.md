# 询问协议（Phase 0 与 Phase 3）

## Phase 0 — 检索前必问（一次问清，允许分批）

目的：锁定范围与约束。逐项问，等用户回答；用户跳过就记录“未提供”并按默认继续。

1. **研究问题/方向**：给一句可证伪的科学问题，或一段方向描述。
   - 若模糊，先复述你的理解并给出 1-2 个收敛后的候选问题，请用户选或改；确认前不检索。
2. **用途**：期刊论文 / 基金申报 / 学位论文开题 / 其他。
3. **目标层级与候选期刊**：目标分区（Q1/Q2）、是否有指定期刊（如 Nature Geoscience、JGR-Atmospheres、ACP、BAMS 等）。
4. **时间预算**：几周/几个月；决定调研深度与计划颗粒度。
5. **已有资源**：可用的观测/再分析/模式数据、算力、团队专长；这些直接决定可行性。
6. **创新幅度**：更偏稳妥增量，还是接受高风险高回报的新颖方向。

## Phase 3 — 计划决策逐项确认（建议 + 请确认或修改）

把研究计划拆成以下 6 项，每项先给结论性建议（附一句文献依据），再问用户“是否采纳 / 需要修改”。全部确认后才写文件。

1. **科学问题**：给出最终一句话问题 + 可验证假设。
2. **创新点**：与现有工作的差异（可引用调研中的文献编号）。
3. **方法路线**：主方法 + 备选；说明为什么适合本问题。
4. **数据方案**：数据源、可得性、缺数据的替代方案。
5. **可行性/风险**：最关键风险与缓解；不可接受时明确说。
6. **时间线与里程碑**：阶段划分与可交付物。

确认话术模板：

“我建议 X（依据：文献 [n] 显示 …）。是否采纳？或告诉我需要改成什么。”

## 默认值

- 用户未提供用途 → 默认按“期刊论文、目标 Q1”规划。
- 未提供时间预算 → 默认 3 个月研究计划。
- 未提供创新幅度 → 默认“稳妥增量 + 一到两处可验证新意”。
- 默认输出目录 `<cwd>/studies/<slug>/`；cwd 不是明确研究目录时先问。
