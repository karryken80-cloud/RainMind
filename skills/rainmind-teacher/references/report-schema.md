# review-report.md 结构

- 稿件信息：slug、标题、目标期刊、审稿日期、稿件版本
- 总结：一句话总体评价
- Major Concerns（逐条：位置 + 问题 + 修改建议 + 分类 + 是否 blocking + 是否需补实验）
- Minor Comments（逐条：位置 + 问题 + 修改建议 + 分类 + 状态）
- 图问题
- 公式问题
- 语言问题
- 科学性问题与建议
- 实验必要性判断：必须补充 / 强烈建议 / 可暂缓 / 不需要
- 推荐意见：接受 / 小修 / 大修 / 拒稿（附理由）

分类字段说明：

- `text`：仅改写文字、图注或格式。
- `analysis`：可用已有数据或预测重新分析。
- `experiment`：需要重新训练或新增实验设计。
- `data`：需要新增外部数据或官方基线。
- `reject`：意见不成立或不适用于本研究，需写出理由。
